## 2. 删除范围和保留范围

设置页第一次确认明确列出：

1. savedExamples：已保存牌例。
2. trashExamples：回收站。
3. draft：原 current 输入、临时调整及编辑副本信息。
4. Settings / Preferences：本应用的 `mahjong.preferences`，不调用 localStorage.clear。
5. ruleSnapshots：历史规则最小快照。
6. rulePackageMetadata：本地规则元数据。
7. migrationBackups：本地迁移安全备份。

不删除应用文件、内置核心 RulePackage、其他站点数据或不属于本应用的 localStorage key。没有实现 PWA Cache 清理或 Update。

成功后重新初始化安全默认偏好、空 Calculator、空 Command History / Saved 会话。Draft 表保留一个新的空 current 及编辑租约，用于安全默认值及迟到旧写入防护；不保留被删除的牌面。

## 3. Use Case / Port / 事务

- Application 的 `LocalDataManagement` 统一执行两次确认、备份选择、暂停本标签写入、清除和重置；UI 只提供确认选择并显示结果。
- 第二次确认提供取消、先导出完整备份再清除、明确不备份永久清除。
- `BackupExportPort.exportFullBackup()` 抛错或拒绝时，不调用清除，不自动降级为“不备份”。
- M9 组合根注入明确不可用的导出适配入口，显示尚未接入 M10，拒绝该分支；没有伪造下载、空 JSON 或“备份成功”。
- 单元测试用可控 Port 验证成功导出后才清除的顺序；这不是正式 Full Backup Adapter。
- `DexieLocalData` 在六表同一读写事务内复核当前 Draft lease owner/token/expiration。等待导出期间接管的旧标签不能执行清除。
- 同事务清空用户记录并写入空白、带新 writeToken 的 Draft，拒绝旧标签迟到写入和旧牌面复活。
- 偏好原始值在操作前保留，并检查期间是否改变。可捕获事务失败时回滚 IndexedDB，补偿恢复已移除的偏好；成功后才更新内存默认值。
- 存储错误进入统一 Temporary Mode，不显示虚假成功；业务编辑权冲突不被冒称为 Quota。

## 6. 已知边界

- 用户不选择明确“不备份”，且正式备份 Port 不可用时，清除不会执行。这是保护要求，不是静默跳过备份。
- localStorage 与 IndexedDB 没有跨存储原生原子事务；当前处理可捕获错误的补偿恢复，不承诺系统强杀期间的跨存储绝对原子性。
- 真正的导出文件内容、恢复 roundtrip、移动设备文件行为属于 M10/M11 集成验证，本轮未实现或冒称通过。
- 本轮清除测试只作用于隔离的测试数据库和浏览器上下文，没有清除用户日常浏览器的本地牌例。
